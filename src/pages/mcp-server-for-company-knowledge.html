CommonIndex is an MCP server for everything your team knows. Connect an MCP client to it and your agent can read and update docs, dashboards, experiments, artifacts, skills and conversations directly, limited to what the person it acts for may see.

What the agent gets

Every operation in CommonIndex is also an MCP tool, generated from the same registry as the app's API, so the two never drift apart. That is more than 170 tools today, including:

  • Docs: docs.search, docs.get, docs.propose, docs.revise
  • Dashboards: dashboards.render returns the numbers, each tied to an agreed metric definition
  • Experiments: experiments.readout returns the result with its statistics and sample-ratio check
  • Conversations: messages.list and messages.post, so an agent can answer in a comment thread
  • Search: one search across every collection the person may read

The server also offers context resources: a generated guide to your datasets, metric definitions and experiments, so an agent knows how to read a number before it quotes one. It is regenerated on every read, so it is never stale.

Permissions come with it

An agent connects with a token that belongs to an actor in your workspace. Every tool call passes the same access check as the app: if the person cannot open a private doc, neither can their agent. Agents can also be limited to proposing changes that a person approves. Workspace admins see everything, and every change is recorded with who made it.

How to connect

  1. Set up CommonIndex on your servers with the guide in the repository.
  2. Create a token for the agent, then print the client configuration with make mcp-config.
  3. Paste it into your MCP client. The CommonIndex MCP server runs as a local process (stdio) alongside the client.

Why not a RAG pipeline?

A retrieval pipeline copies your knowledge into a separate store and serves agents that copy. With CommonIndex the knowledge already lives in one place, so the agent reads the source itself, always current, with permissions applied. Read why we skip the pipeline.
