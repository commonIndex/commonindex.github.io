Everything your team knows. One index.

One source, two doors

People use the app. Agents use MCP. They see the same thing.

Every operation is an API call and an MCP tool, generated from one registry, so the two never drift apart.

People, in the app

Everything you may see, one search away.

Write docs and build dashboards with AI beside you, comment on any item, and find anything with one command bar.

Agents, over MCP

Any MCP client. 170+ tools.

→ dashboards.render {"dashboard_id": "DASH-12"}← { "title": "Checkout · weekly", … }→ experiments.readout {"experiment_id": "EXP-7"}← { "lift": "+3.1%", "srm": "ok" }→ messages.post {"subject_id": "DOC-41", …}← posted in the thread

Each with the same permission check as the app.

No RAG pipeline

Nothing to export, chunk, embed or keep in sync.

Retrieval pipelines serve agents a copy that is already out of date. Here the knowledge already lives in one place, so agents read the source, always current, and only what their person may see.

Export→Chunk→Embed→Vector store→Stale copy
Your agent→MCP→CommonIndex
